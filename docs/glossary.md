# Glossary

Canonical names for *Everwrit Online*. When a doc and this file disagree, this file wins — update it first, then the docs.

## World & cosmology

| Term | Meaning |
|---|---|
| **Everwrit Online** | Working title of the game. |
| **Vellumar** | The world. Named for the vellum the gods wrote it on. |
| **The Scribe-Gods** | The faded or withdrawn gods who wrote Vellumar. |
| **The First Script** | The divine text the gods used to write Vellumar into being. |
| **The Sundering of the Quill** | The war among the gods that shattered the First Script. |
| **The Chronicle** | The game's "System": the shattered First Script, now a force of nature that measures, levels, titles, and records every living thing. Voiced by the AI Narrator. |
| **The Unwritten** | Player characters: souls the Chronicle has never recorded before. The Chronicle rewrites them when they die. |
| **The Redactor** | Main antagonist. Once the gods' Editor; now erasing Vellumar so it can be rewritten "correctly." |
| **The Blotted** | Creatures and places partly erased by the Redactor: ink-black, with missing pieces and glitching text. |
| **The Margin** | The blank space outside the Chronicle, where erased things go. The Blotted come from here. |
| **Waystone** | Respawn and fast-travel point where the Chronicle rewrites fallen Unwritten. |

## Systems

| Term | Meaning |
|---|---|
| **Attributes** | STR (Strength), AGI (Agility), VIT (Vitality), INT (Intellect), WIS (Wisdom), PER (Perception). |
| **Free points** | Two attribute points per level that the player assigns. |
| **Proficiency** | A skill's own level (1–10), raised by using the skill. |
| **Evolution** | At Proficiency 10, a skill can become one of 2–3 sidegrade variants. |
| **Class Path** | A specialization offered at levels 10, 20, and 30. The options depend on the player's **Deeds**. |
| **Deeds** | Counters the server tracks (blocks, heals, kills by type, discoveries) that unlock Paths, titles, and hidden quests. |
| **Title** | Earned by deeds. One can be active; it gives a small bonus or is cosmetic. |
| **World First** | The first completion of a feat on a server. It is announced to everyone on the server and recorded in the Hall of Record. |
| **Unique** | Item rarity with only one copy per server at a time. |
| **Analyze** | A skill every character has. It reveals enemy stat sheets; higher Proficiency reveals more. |
| **Faded** | Short debuff after respawning. |
| **Chronicle Journal** | A player's sessions written up as LitRPG novel chapters, collected into **Volumes**. |
| **Chronicle Event** | A timed world or seasonal event. |
| **Chronicle Legacy** | Account-wide XP bonus and shared perks unlocked when a character reaches level 30. |
| **Annotation** | A Scrivener mark on an ally or enemy that other abilities consume. |
| **Annotated** (difficulty) | Hard mode for 5-player dungeons. |
| **Marks of Record** | Dungeon and raid currency with a weekly cap. |
| **House Favor** | Great House reputation currency. |
| **Companies** | Guilds. |
| **Summoning Circle** | The group finder. |
| **AI Narrator** | The service that gives the Chronicle and key NPCs a voice through an LLM. It never decides mechanics. |
